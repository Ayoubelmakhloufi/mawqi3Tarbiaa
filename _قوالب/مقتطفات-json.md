# مقتطفات JSON جاهزة للنسخ

> افحص الملف دائمًا في <https://jsonlint.com> قبل الرفع.
> **فاصلة واحدة ناقصة أو زائدة تُعطّل كل قوائم المقالات في الموقع.**

---

## 1. مدخل مقال في `data/articles.json`

يُضاف **في أعلى القائمة** (بعد `[` مباشرة) مع فاصلة `,` بعد القوس المغلق:

```json
{
  "slug": "ism-lataini-bil-shurat",
  "section": "dourous",
  "title": "عنوان المقال بين 50 و65 حرفًا",
  "description": "وصف بين 80 و160 حرفًا — هذا ما يظهر في نتائج جوجل، اكتبه بعناية.",
  "date": "2026-08-05",
  "updated": "2026-09-01",
  "image": "/assets/img/articles/ism-lataini-bil-shurat.jpg",
  "tags": ["وسم أول", "وسم ثانٍ"],
  "featured": false,
  "draft": false
}
```

### الحد الأدنى (الحقول الإلزامية فقط)

```json
{
  "slug": "ism-lataini",
  "section": "dourous",
  "title": "عنوان المقال",
  "description": "وصف المقال بين 80 و160 حرفًا يظهر في نتائج البحث.",
  "date": "2026-08-05"
}
```

### قيم `section` المسموحة

| القيمة | القسم |
|---|---|
| `mobarat-attaalim` | مباراة التعليم بالمغرب |
| `ijaza-tarbiya` | الإجازة في التربية والمدارس العليا |
| `takwin-crmef` | التكوين بالمراكز الجهوية |
| `taalim-raqami` | التعليم الرقمي |
| `dourous` | دروس علوم التربية والديداكتيك |
| `maktaba` | المكتبة الرقمية |
| `adawat` | الأدوات والحاسبات |
| `mostajaddat` | مستجدات وأخبار |

### حيل عملية

| تريد… | افعل |
|---|---|
| جدولة مقال لتاريخ لاحق | ضع `date` في المستقبل — يختفي حتى يحين موعده |
| إخفاء مقال مؤقتًا | `"draft": true` |
| إبراز مقال في رأس قسمه | `"featured": true` |
| إظهار شارة «حُدِّث في…» | أضف `"updated": "2026-09-01"` |

## 2. مدخل قسم في `data/sections.json`

```json
{
  "slug": "tadbir-alfasl",
  "title": "تدبير الفصل الدراسي",
  "nav": "تدبير الفصل",
  "group": "maktaba",
  "icon": "fa-users-rectangle",
  "tint": "sky",
  "desc": "وصف القسم بين 80 و160 حرفًا — يظهر في نتائج البحث لصفحة القسم.",
  "tagline": "جملة قصيرة تظهر تحت عنوان القسم"
}
```

### شرح الحقول

| الحقل | ماذا يفعل |
|---|---|
| `slug` | اسم المجلد والرابط. لاتيني بشرطات. |
| `title` | العنوان الكامل — يظهر كـ`h1` وفي `<title>` |
| `nav` | الاسم المختصر في القائمة وفتات الخبز |
| `group` | مجموعة القائمة في الهيدر: `concours` أو `maktaba` أو `main` |
| `icon` | اسم أيقونة Font Awesome بدون `fas` |
| `tint` | لون البطاقة |
| `desc` | وصف SEO |
| `tagline` | جملة تحت العنوان |

### الألوان المتاحة لـ `tint`

`emerald` · `teal` · `lime` · `sky` · `amber` · `indigo` · `rose` · `orange`

> لون غير موجود في هذه القائمة **لن يعمل** (الأصناف مُصرَّفة مسبقًا في CSS).

### أيقونات Font Awesome مقترحة

`fa-chalkboard-user` · `fa-graduation-cap` · `fa-school` · `fa-laptop-code` ·
`fa-book-open` · `fa-folder-open` · `fa-calculator` · `fa-bullhorn` ·
`fa-users-rectangle` · `fa-clipboard-check` · `fa-lightbulb` · `fa-file-lines`

ابحث عن غيرها في <https://fontawesome.com/search?o=r&m=free>
واستعمل الاسم كما هو **بدون** بادئة `fas`.

## 3. سطر في `sitemap.php` لصفحة مستقلة

يُضاف في قائمة `$urls`:

```php
$urls[] = ['loc' => '/man-nahnu', 'changefreq' => 'yearly', 'priority' => '0.5', 'lastmod' => tb_file_date('man-nahnu.php')];
```

| `priority` | متى |
|---|---|
| `1.0` | الرئيسية |
| `0.9` | الأقسام والأدوات |
| `0.8` | المقالات |
| `0.5` | صفحات ثانوية |
| `0.3` | صفحات قانونية |

## 4. قاعدة `.htaccess` لرابط عربي

**لا تسمِّ الملف بالعربية.** أبقِ اسمه لاتينيًا وأضف في قسم 3 من `.htaccess`:

```apache
# رابط عربي عمومي + ملف لاتيني آمن
RewriteRule ^اسم_الصفحة_بالعربية/?$ ism-assafha.php [L]
```

ثم اجعل `'canonical'` في `$meta` هو الرابط العربي:

```php
'canonical' => '/اسم_الصفحة_بالعربية',
```

> `tb_abs()` يتكفّل تلقائيًا بترميز الحروف العربية في `canonical` و`og:url` وخريطة الموقع.

## 5. أخطاء JSON الأكثر شيوعًا

| الخطأ | الشكل | التصحيح |
|---|---|---|
| فاصلة بعد آخر عنصر | `"date": "2026-08-05",` ثم `}` | احذف الفاصلة الأخيرة |
| فاصلة ناقصة بين مدخلين | `}` ثم `{` | ضع `},` |
| علامات تنصيص عربية | `„عنوان”` | استعمل `"` الإنجليزية فقط |
| قيمة منطقية بين تنصيص | `"featured": "true"` | `"featured": true` بلا تنصيص |
| تاريخ بصيغة خاطئة | `"05-08-2026"` | `"2026-08-05"` |
