# 🔍 أدوات الفحص

> **محلي فقط — لا تُرفع إلى الخادم.**

## التشغيل

```bash
node _fahs/fahs.js
```

يشغّل الفحوص الثلاثة ويخرج برمز خطأ إن فشل أيها. شغّله **قبل كل رفع**.

وللفحص المنفرد:

```bash
node _fahs/bayanat.js     # لا يحتاج خادمًا
node _fahs/css.js         # لا يحتاج خادمًا
node _fahs/safahat.js     # يحتاج الخادم يعمل
```

الفحص الثالث يحتاج خادم المعاينة في نافذة مستقلة:

```bash
php -S localhost:8000 _dev-router.php
```

> ولإظهار تحذيرات PHP في جسم الصفحة (وهو ما يفحصه `safahat.js`) شغّله هكذا:
> ```bash
> php -d error_reporting=E_ALL -d display_errors=1 -S localhost:8000 _dev-router.php
> ```

## ماذا يفحص كل واحد؟

### `bayanat.js` — البيانات

- سلامة صياغة كل ملف في `data/` (فاصلة ناقصة تُخفي المحتوى كله)
- كل مقال له ملف `maqalat/<slug>.php`، وكل قسم له مجلده
- كل اختبار له `ikhtibarat/<slug>/index.php`، وكل ملف وثائق له صفحته
- الأسئلة: أربعة خيارات · `c` داخل المجال · لا خيارات مكررة · لا سؤال مكرر
- لا `class=` ولا وسوم ممنوعة في نصوص المحتوى
- الألوان من الثمانية المسموحة فقط
- مصطلحات `r` في المعجم تحيل على مصطلحات موجودة فعلًا
- **أعداد مكتوبة يدويًا في PHP تقادمت عن مصدرها** («52 سؤالًا» وقد صارت 350)

### `css.js` — أصناف Tailwind

- كل صنف مستعمل موجود فعلًا في `assets/css/tarbiaa.css` المُصرَّف
- **أصناف مُولَّدة ديناميكيًا** (`sm:grid-cols-<?= $n ?>`) — لا يراها ماسح Tailwind أبدًا

> الصنف غير المُصرَّف **لا يُنتج خطأ** — يُهمَل بصمت فيختل الشكل بلا أي رسالة.
> هذا الفحص هو الوحيد الذي يكشفه.

### `safahat.js` — الصفحات

- كل رابط في `sitemap.xml` يرجع **200**
- **صفر تحذيرات PHP** — Warning و Notice و Undefined و Deprecated، لا الأخطاء القاتلة فقط
- `/data/` و`/partials/` و`_dev-router.php` محجوبة (403)
- صفحة 404 تعمل

## توسيعه

كل ملف يصدّر `run()` تُرجع `true` عند النجاح. لإضافة فحص جديد:
أنشئ ملفًا بالنمط نفسه، ثم أضفه إلى قائمة `checks` في `fahs.js`.

**اختبر أي فحص جديد بكسر متعمَّد** ثم تأكد أنه أمسكه — فحص لا يفشل أبدًا لا قيمة له.
